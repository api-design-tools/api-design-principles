RFC 9457 problem details and codes

Return application/problem+json on error responses, checked by ADP-008 and ADP-009.

Standard problem details payload

RFC 9457 obsoleted RFC 7807 with a single machine-readable error envelope.

{
  "type": "https://api.example.com/errors/validation-error",
  "title": "Your request parameters did not validate",
  "status": 422,
  "detail": "Field 'items[0].quantity' must be an integer >= 1.",
  "instance": "/v1/orders#req_01J9Z8X2M9K4"
}
