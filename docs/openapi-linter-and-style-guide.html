OpenAPI Linter, Breaking-Change Diff & GitHub Action (2026)

Run api_validator.py locally or in GitHub Actions using standard library Python 3.9+. Supports JSON and YAML specs, breaking-change diffs, built-in presets, and SARIF 2.1.0 security reports.

# Lint YAML or JSON OpenAPI specs with an industry preset
python3 api_validator.py --spec examples/orders-api-good.openapi.yaml --preset stripe-style

# Detect breaking contract changes between two OpenAPI revisions
python3 api_validator.py --diff openapi.base.json openapi.head.json --format markdown

# Export SARIF 2.1.0 for GitHub Code Scanning
python3 api_validator.py --spec openapi.json --format sarif --output api-lint.sarif
