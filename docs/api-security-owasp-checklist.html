Prevent BOLA / IDOR (ADP-023) and ID enumeration (ADP-024)

Scope every single-record database query by the authenticated tenant (WHERE id = $1 AND tenant_id = $2) and use prefixed ULID or UUIDv7 identifiers such as ord_01J9Z4K8M2 to stop ID enumeration.
